# 릴리스 문구

다른 프로젝트와 같은 짧고 기능 중심의 말투를 사용합니다. 한 문장으로 가장 큰 변화를 설명하고, 실제 사용자에게 보이는 변경 3~5개를 적습니다. 필요한 경우에만 설치·권한·업데이트 안내를 덧붙입니다. 내부 작업 기록, 파일 목록, 테스트 로그와 과장된 표현은 넣지 않습니다.

## 다음 릴리스 초안 · 아직 발행하지 않음

처음 설정하고 업데이트하는 과정을 더 간결하게 다듬었어요.

- 첫 실행에서 저장 위치와 문서 폴더 접근을 안내하고, 권한을 바꾼 뒤 다시 시도할 수 있어요.
- 업데이트 창에서 새 버전을 확인하고 자동 알림을 켜거나 끌 수 있어요. 알림 설정은 자동 다운로드·설치와 별개예요.
- 활성 필터와 검색 결과가 없는 상태를 더 알아보기 쉽게 정리했어요.
- DMG에서 앱을 Applications로 드래그해 설치할 수 있어요.

macOS 14 이상과 Apple Silicon Mac을 지원합니다. 기존 사용자는 앱 내부 업데이트를 이용할 수 있고, 논문과 설정은 유지돼요. 이 베타 빌드는 Apple 공증을 받지 않았으므로 처음 실행이 차단되면 개인정보 보호 및 보안에서 **그래도 열기**를 선택해 주세요.

## 발행 전

실제 배포 파일의 아키텍처·서명·공증 상태와 검증 결과에 맞춰 안내를 확인합니다. 버전 번호를 정하고 사용자 검토를 받은 뒤 본문에 복사하며, 이 문서는 릴리스 첨부 자산으로 올리지 않습니다.
